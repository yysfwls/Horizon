# Evaluation goal

Evaluate how useful a Web development item is to working developers.

# Scoring rubric

- **9-10:** A major browser, platform, language, framework, or architectural change.
- **7-8:** A substantive release, compatibility change, technique, or deep engineering analysis.
- **5-6:** A useful tutorial, library, performance improvement, or focused implementation lesson.
- **3-4:** Routine updates, shallow tips, duplicated advice, or promotional content.
- **0-2:** Off-topic, obsolete, misleading, or content without actionable technical value.

Prioritize correctness, technical depth, compatibility impact, reproducibility, and practical value. Use three to five specific topic tags.
